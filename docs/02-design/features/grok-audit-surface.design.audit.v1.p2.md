## Summary
`docs/02-design/features/grok-audit-surface.design.md` (v1.0) covers the eight-mode probe architecture, wrapper pins, and 81-test breakdown, and passes `h_mad_precheck_doc.py` and `h_mad_expect_screens.py` with zero errors. However, four build-impacting defects must be fixed before the implementation plan: D3 excludes `auditcycle.txt` from AC-2.7's calibration-data set and `main_leak` trigger (i) even though `h_mad_audit_cycle.py` prints a `Premise checklist:` containing every calibration finding and its seeded `quote:` spans to `auditcycle.txt` on every `FAIL` cycle; `extract` mode has no exported commit tree containing `s2/` when it runs in S2 and its `candidate-fabrication` check looks up live phase-document `quote:` paths that do not exist in the exported calibration tree; D1's single-refusal-vocabulary rule (`SEEDSCORE: UNREADABLE reason=<r>` in every mode except `smoke`) contradicts D9 and Error Handling Strategy (`COMMIT: REFUSED` and `RECORD:` tokens); and `extract`/`score` omit Spec AC-4.5's separately published should-fix seed hits and Spec FR-6's observational per-phase and per-class splits.
