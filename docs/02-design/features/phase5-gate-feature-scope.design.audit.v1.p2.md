## Summary
`docs/02-design/features/phase5-gate-feature-scope.design.md` (v1.2) covers all 88 acceptance criteria in `Test Boundaries` and passes `h_mad_doc_shape_check.py` and `h_mad_test_boundaries_check.py`, with a clean streaming `TreeOracle` design and atomic single-result writer refactor. However, six build-affecting defects break gate contracts, wire-mutation discrimination, or fail-closed invariants: `Scan.write(target)` and wire rows 5/11 pull off-chain session files onto `production`/`listed` writes (or leave scope mutants unkillable behind `read_chain`), §8 appends `describe(applied)` after agy's mandatory trailing `kind=` token, §4's `recorded_checkout` order misclassifies regular files (AC-4.6) and hangs on FIFOs while `checkout_of` treats broken worktree gitfiles and `.git`/bare repos as positively outside every work tree, §5's out-of-root `listing` table contradicts `target-unknown` ("a target in no work tree") and `Test Boundaries` (`Mocked dependencies: none` for AC-3.4/AC-3.5), and [redacted: private, operator record]. Two further build ambiguities in `landing_lanes.py` and `scope --target` should also be tightened before Phase 5.
