## Must-fix
- AC-5.5's `test_timeout_survives_a_group_that_already_emptied` is circular as specified: its patched `killpg` first sends the real `SIGKILL` and then polls `os.kill(pgid, 0)` for `ProcessLookupError` before it raises, but the direct `Popen` child remains a zombie until the helper's later `communicate()`/`wait()` reaps it. The poll therefore cannot complete on the stated path (confirmed locally: the PID existed after `killpg` and disappeared only after `Popen.wait()`), so the named race guard hangs or needs an unstated escape hatch rather than proving the `ProcessLookupError` handling. Revise the fixture to reap/poll the direct child within the fake, or otherwise construct an actually empty process group, and state the bounded cleanup/verification sequence; an unexecutable named guard violates the test-discrimination requirement for this load-bearing race.
