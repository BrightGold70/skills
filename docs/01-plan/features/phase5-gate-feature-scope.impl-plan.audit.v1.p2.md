## Summary
`phase5-gate-feature-scope.impl-plan.md` (v1.0) maps all 88 spec acceptance criteria and 42 wiring tasks across steps S0–S11 with consistent per-task test and mutation-row deltas, but six build-class defects will halt or break Phase 5 execution as written. All 63 `WIRE-PIN` declarations omit the repo-relative `h-mad/` prefix required by `.h-mad/wires.jsonl` and `h_mad_wire_registry.py verify`, `Stated counts` on shared/existing test files omit prior tests collected by `h_mad_assemble_tdd.py`, Convention 5 mandates a `symbol` key that `h_mad_mutation_harness.py` refuses on JSON targets, Task 29's `H-LIST-INROOT` re-anchor target leaves the mutant `SURVIVED`, and cross-task signatures for `arming_refusal`, `str`/`Path` parameters, and codex `arming_target`'s `base` do not align.
