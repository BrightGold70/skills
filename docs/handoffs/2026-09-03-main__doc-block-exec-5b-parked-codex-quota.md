## Key Learnings

- **Every round found exactly one new serial hole, and roughly half were mine.** The reviewers reach one design gap per cycle (collect stage → poll guard → bounded wait → field escaping → quoting → C1/U+2028 → argparse exit-2 → form collision → rollback race), and about half the must-fixes were fix-introduced: a dropped `re` import, a count I said was five when it was six, a test name I invented (`test_cli_subst_refusals`), a test case whose first-arm ENOTDIR path creates nothing to roll back, `arg==V` under a grammar I had just made quoted, a `type-walk` justification that walks nothing. The mechanical fail-closed edit scripts (exact-once anchors, refuse on mismatch) prevented silent misses but not wrong content; the value sweep across spec/plan/design/impl-plan was the step most often skipped (the empty-key delegation sentence survived in spec and plan two rounds after the design changed).
- **The assembler's preflight flagged a verbatim `rf"^#{{1,{level}}} "` inside a fenced payload as an unresolved `{{ONLY:…}}` conditional** — fixed in `b59e05e` (fence-aware scan, test added, 44 passed). A literal mutation payload quoting source with doubled braces is legitimate content.
- **`exec_module` without `sys.modules[spec.name]` fails for any module with a frozen `@dataclass` under `from __future__ import annotations`** (`dataclasses._is_type` dereferences `sys.modules[cls.__module__]`; measured `AttributeError` on 3.11.8). The connection-only delegation-revert mutant registers its private instance under `_h_mad_doc_block_exec_private` first.
- **agy's substantive passes are the ones with tool counts ≥ 5** (c58: 16, c62: 70, c69: 42, c73: 3 but measured, c77: 13): they found the FIFO-never-reaches-`fstat` defect, the six-rows-not-five count, the RunResult keyword bug, the `SIGKILL` prefix. Low-evidence passes (1–2 tools) returned PASS every time and once fabricated two test names and a "Task 6". Once agy ran a whole-home `find` for the not-yet-existing module and timed itself out (`no_report` on all three legs that round).
- **Codex's usage limit surfaces as `EMPTY final message — agent exited 1`**, and a complete `--report-file` may already be on disk (design c81 was; `collect-report` still said MISSING for want of the `.done` marker). Read the codex log tail for `usage limit` before re-dispatching (memory `feedback_codex_usage_limit_2026_09_03`).
- `json.dumps(str, ensure_ascii=False)` leaves DEL, the C1 range (U+0085) and U+2028/2029 literal, all of which `str.splitlines()` breaks on; a reader-less FIFO fails at `os.open` with `ENXIO` under `O_NONBLOCK` and never reaches an `S_ISREG` check, while `/dev/null` opens and is non-regular; `subprocess.TimeoutExpired` needs `(cmd, timeout)`; `hmad-dispatch run --timeout N -- cmd` propagates rc and returns 124 on expiry — all measured this session and now cited in the docs.
